# Waltham produktunivers — preview

Denne mappe indeholder et selvstændigt website-udkast i `index.html`.

## Sådan ser du siden
Dobbeltklik på `index.html`, eller træk filen ind i Safari/Chrome.

## Hvad prototypen indeholder
- Produktfokuseret forside
- Digitalt sagsrum som hovedprodukt
- Idétest, kundesparring, AI-gennemgang og fast sparringsforløb
- Simuleret chatbot
- Bevar Nyborg Fjord som demonstrationscase
- Artikelunivers
- Åben idébank
- Nyhedsbrev og kontaktindgang
- Diskret troværdighedssektion i stedet for fuld CV

## Næste tekniske trin
1. Erstat den nuværende `index.html` i GitHub-repositoriet.
2. Tilpas e-mailadresse, links og navn.
3. Kobl formular til Netlify Forms, Buttondown, Mailchimp eller Brevo.
4. Kobl chatbotten til en sikker backend og en afgrænset vidensbase.
5. Opret separate artikel- og casesider.
